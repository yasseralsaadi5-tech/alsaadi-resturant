# مطعم و مطبخ السعدي — الموقع ولوحة التحكم

## ⚠️ ملاحظة صادقة قبل البدء
هذا الكود **لم يُبنَ (`npm run build`) فعلياً** في بيئة إنشائه، لأن تلك البيئة
بلا اتصال إنترنت (تم التحقق: `npm install` رجع خطأ 403 من سجل npm). كل شيء
آخر — الجداول، RLS، الـ Storage bucket، البيانات — تم إنشاؤه والتحقق منه
فعلياً عبر Supabase MCP (التفاصيل في `journal/testing.md`). يجب تشغيل الخطوات
التالية محلياً على جهازك للتحقق من البناء.

## 1. التثبيت
```bash
npm install
cp .env.local.example .env.local
npm run dev
```
افتح http://localhost:3000

## 2. تفعيل أول حساب أدمن (خطوة يدوية لمرة واحدة، ومقصودة أمنياً)
1. افتح الموقع محلياً → `/admin/login` → بوّب "إنشاء حساب" وسجّل بريدك وكلمة مرور.
2. في لوحة Supabase (https://supabase.com/dashboard/project/znqnyvsblynqnimkrrff) → Authentication → Users، انسخ الـ **User UID** الخاص بالحساب الذي أنشأته.
3. في SQL Editor بنفس المشروع، نفّذ:
   ```sql
   insert into public.profiles (user_id, full_name, role)
   values ('USER_UID_هنا', 'اسمك', 'admin');
   ```
4. سجّل الدخول من `/admin/login` مرة أخرى — ستصل الآن إلى لوحة التحكم.

هذه الخطوة مقصودة: السماح لأي شخص يسجل حساباً بالحصول على صلاحيات إدارة
تلقائياً كان سيشكل ثغرة أمنية حقيقية على موقع عام.

## 3. ما هو حقيقي الآن وما ينتظر منك
| العنصر | الحالة |
|---|---|
| قاعدة البيانات + RLS + Storage | ✅ حقيقي وفعّال (مشروع znqnyvsblynqnimkrrff) |
| 3 تصنيفات + 19 صنفاً | ✅ حقيقي، بدون أسعار/أوصاف مُخترعة |
| صورتا منسف وشاورما عربي | ✅ حقيقيتان، مربوطتان فعلياً |
| باقي صور الأصناف (13) | ⏳ فارغة عمداً — ارفعها من لوحة التحكم عند توفرها |
| الأسعار | ⏳ "السعر يحدد لاحقاً" لكل الأصناف — أدخلها من لوحة التحكم |
| محفظة الدفع المحلية | ⏳ معطّلة في الواجهة حتى تُحدد اسم المحفظة |
| `npm run build` فعلياً | ⏳ لم يُختبر في بيئة الإنشاء (بلا إنترنت) — اختبره أنت |
| اختبار متصفح حقيقي/أحجام شاشات | ⏳ لم يُختبر فعلياً — التصميم mobile-first نظرياً فقط |

## 4. هيكل المشروع
راجع `CLAUDE.md` و`journal/decisions.md` لكل القرارات التقنية والأمنية،
و`journal/testing.md` لسجل دقيق بما تم اختباره فعلاً وما لم يُختبر.

## 5. النشر
أي منصة تدعم Next.js 16 (Vercel مثلاً). أضف متغيرات `.env.local` نفسها في
إعدادات المنصة، وأضف نطاق موقعك المنشور إلى Supabase Auth → URL Configuration.
